## 🛑 What is this?

**Coding Partner** is not a standard developer utility. It was built out of pure frustration with modern tooling. Traditional linters gently underline your syntax errors in soft yellow. We realized the world didn't need another generic formatter; it needed brutal honesty.

Powered by the **SnarkLintProtocol**, this suite of browser-based tools evaluates your logic structure, naming ambiguity, and obsolete practices, delivering highly specific, satirical critiques to enforce clean architecture.

## 🛠 The Tools

This repository contains 6 distinct client-side applications built for developer accountability:

1. **The Sassy Code Roaster:** Paste your questionable HTML, CSS, or JS. The engine calculates exactly how many bad decisions you made in real-time.
2. **Git Excuse Generator:** Broken staging? Generate a cryptically authentic, highly technical developer alibi to blame DevOps or cosmic rays.
3. **Regex Destructor:** Test your regular expressions while discovering why your complex pattern should just be an if-statement.
4. **Div Centering Lab:** A safe, interactive playground to test flexbox and grid alignment techniques without destroying your production CSS.
5. **Variable Name Critic:** Audit variable identifiers (e.g., `temp2` or `dataArr`) and receive strict linguistic critiques.
6. **"Works on My Machine" Cert:** Generate an official compliance certificate to deny production culpability and transfer blame to infrastructure.

## ⚡ Architecture & Performance

This project is an exercise in **Zero-Bloat Engineering**. 

* **Zero Frameworks:** No React, no Vue, no Angular.
* **Zero Compilers:** No Webpack or Vite build steps required.
* **Zero Dependencies:** No `node_modules`. 
* **100% Client-Side:** All regex parsing, AST evaluations, and logic checks run securely within the browser's JavaScript runtime. Your code snippets are never transmitted to a backend server.
